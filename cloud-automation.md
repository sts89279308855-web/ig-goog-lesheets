# Облачное ведение @goog.lesheets

Источник очереди — queue.json, часовой пояс Asia/Yekaterinburg.

- Instagram daily publishing: ежедневно 20:40 местного времени (15:40 UTC), один пост в день. GitHub может задержать начало задания. Разрешён запуск в пределах двух часов от времени слота. За пределами окна публикация не выполняется.
- Instagram content replenishment: ежедневно 07:17 местного времени. Поддерживает запас на восемь следующих календарных дней, создаёт не больше двух видео за один запуск. Среда и воскресенье — подробные уроки 60–90 секунд; в остальные дни — короткие примеры. Готовые проверенные видео не пересоздаёт и не публикует повторно.
- Источники новых роликов: content-bank.json — подготовленные учебные сценарии и формулы. Рендер, голос Светлана и проверка видео происходят на сервере. Новые видео, сценарии, формулы и обложки сохраняются в репозитории. Никакие платные генераторы не используются.
- После исчерпания подходящих сценариев генератор останавливается с ошибкой и записью в .cloud/generator.json: он не выдаёт повтор старого ролика за новый. Банк нужно пополнять новыми проверенными темами; Codex может делать это при следующих рабочих сеансах.
- Защита от дублей: сверка последних публикаций, одна попытка публикации на дату, сохранённый container_id, подтверждённый media_id. Неясный результат требует сверки; слепого повтора нет.
- Личный аккаунт не используется. Профиль, существующие публикации и Direct не изменяются.

## Постоянный доступ — один раз

Для постоянной работы нужен ключ **Composio Connect** с префиксом `ck_`. Тестовый короткоживущий OAuth-токен не используется.

1. В Composio For You / Connect откройте Settings → Sessions & API Key, скопируйте **существующий** Your API Key. Не нажимайте Regenerate: это отключит другие клиенты.
2. В этом репозитории откройте Settings → Secrets and variables → Actions → New repository secret.
3. Имя секрета: `COMPOSIO_CONSUMER_KEY`. Значение: скопированный ключ. Не добавляйте его в файлы репозитория и не публикуйте в чате.
4. Actions → Instagram daily publishing → Run workflow → mode `audit`: проверка без публикации. После успешной проверки ежедневное расписание уже действует.

Ключ проекта Platform (`ak_`) и CLI user key (`uak_`) не заменяют Connect `ck_` в этой конфигурации. Права ключа относятся к подключённым приложениям пользователя; секрет доступен только серверным заданиям этого репозитория. Источник схемы авторизации: https://docs.composio.dev/kb/guide/consumer-project-boundaries-and-auth-selection

## Проверка и остановка

Состояние: .cloud/publisher.json, .cloud/generator.json, .cloud/publications/YYYY-MM-DD.json; журнал — journal.md. Ручной запуск публикации также соблюдает дневной лимит и временное окно.
Чтобы остановить расписание, Actions → нужное задание → Disable workflow. Отключённый компьютер на эти задания не влияет.

Локальная автоматизация Codex — резерв и редактор тем. До проверки постоянного ключа она может публиковать по прежним правилам; при подтверждённом облачном доступе она не должна конкурировать с облачным постингом.
